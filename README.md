Cargo + Tauri 2 기반 로컬 미디어 플레이어/가사/시각화/마스터링 통합 앱.
m4a를 재생하는 도구가 window나 mac에서 실제로 비용을 내야하는 도구가 많아서 직접 만든 것이다. 오프라인에서 동작하도록 설계하였다. 

## 주요 기능
- M4A / MP3 / WAV / MP4 / WEBM 재생
- Windows 설치 시 `.m4a` 파일 연결 등록
- 곡별 SRT 연결 및 재생목록에 경로 저장
- FFT 막대/웨이브 + 시각화 화면 위 현재 가사 오버레이
- 2-track stereo waveform, Ctrl+휠 zoom, Shift+휠 horizontal pan, click seek
- 재생목록 자동 복원 및 `.jjp` 프로젝트 파일 저장/열기(원본 파일 경로 기억)
- JJaIMsae Player 전용 Library 폴더로 음원/SRT/커버 복사 및 metadata.json 관리
- 곡별 커버 이미지 연결
- FFmpeg가 설치된 PC에서 MP3/WAV 변환
- `To Mastering`: 포함된 SunoMaster/JJaIMsae Mastering 창으로 현재 곡 전달
- `마스터링 열기`: 별도 창이나 외부 팝업 없이 플레이어 본창 내부 패널로 실행
- Mastering WAV 생성 시 Player의 `mastered` 폴더에도 결과 저장

## cargo를 설치하는 방법 

Tauri 애플리케이션 빌드(`cargo tauri build`)를 수행하기 위해서는 사전에 Rust 프로그래밍 언어와 패키지 관리자인 Cargo를 설치해야 한다. 다음의 단계별 절차를 통해 시스템에 환경을 구축할 수 있다.

### 1. Rust 및 Cargo 설치 (rustup 활용)
Rust와 Cargo는 공식 설치 도구인 `rustup`을 통해 일괄적으로 설치할 수 있다.

* **Windows 사용자:**
  1. 공식 웹사이트나 명령 프롬프트(CMD)를 통해 `rustup-init.exe`를 다운로드하거나, PowerShell에서 공식 설치 스크립트를 실행한다.
  2. 웹 기반 설치 프로그램(`rustup-init.exe`)을 실행한 뒤, 기본 설정값(Default)인 `1`번을 입력하고 엔터를 눌러 설치를 진행한다.
  3. Windows의 경우 C++ 빌드 도구인 **Visual Studio C++ Build Tools**가 추가로 요구될 수 있으므로, 안내에 따라 해당 도구를 설치하였다.

* **macOS 및 Linux 사용자:**
  1. 터미널(Terminal)을 연 후, 다음의 공식 설치 명령어를 입력하고 실행하였다:
     ```bash
     curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
     ```
  2. 화면에 나타나는 안내에 따라 기본 설치(1번)를 선택하였다.

### 2. 환경 변수 적용
설치가 완료된 직후, 터미널 세션에 경로(PATH)가 즉시 반영되지 않을 수 있다.
* 아래의 명령어를 입력하여 현재 터미널에 환경 변수를 적용하였다:
  ```bash
  source "$HOME/.cargo/env"
  ```
* 또는, 터미널 창을 완전히 닫은 후 새로 열었다.

### 3. 설치 검증
Cargo와 Rust가 정상적으로 설치되었는지 확인하기 위해 버전 정보를 조회하였다.

1. **Rust 컴파일러 버전 확인:**
   ```bash
   rustc --version
   ```
2. **Cargo 패키지 관리자 버전 확인:**
   ```bash
   cargo --version
   ```

위 두 명령어에서 버전 정보가 정상적으로 출력되었다면, `cargo tauri build`를 수행하기 위한 기본적인 백엔드 환경이 성공적으로 구축된 것으로 평가할 수 있다. 이후 Tauri CLI 설치 및 시스템별 추가 종속성 설치 단계로 이어질 수 있다.


### 앨범 이미지 편집 (IMG Studio)

곡을 선택하고 상단 마스터링 옆의 **IMG 편집**을 누릅니다. PNG/JPG/WebP/GIF 이미지를 업로드하거나 기존 커버를 편집할 수 있습니다.

- 도구는 선택/이동·붓·펜·형광펜·지우개·복제 도장 버튼으로 항상 펼쳐져 있습니다.
- 업로드 옆 **×**는 편집 중인 원본 이미지만 제거하고 텍스트와 그림 레이어는 유지합니다. 실행 취소로 복구할 수 있습니다.
- 이미지 파일을 편집기에 **드래그 앤 드롭**하거나 **Ctrl+V / 붙여넣기** 버튼으로 불러옵니다. PNG/JPG/WebP/GIF를 지원하며, 기존 텍스트 입력란의 텍스트 붙여넣기는 그대로 동작합니다.
- 비율은 정사각형(기본), 3:4, 9:16, 4:3, 16:9입니다. 출력 긴 변을 직접 입력하거나 1600/3000/4096px 버튼을 사용합니다. 최대 출력은 3200만 픽셀입니다.
- 미리보기에서 **마우스 휠**로 커서 위치를 기준으로 확대·축소하고, **텍스트가 없는 곳을 드래그**하여 이미지를 이동합니다. **Alt+드래그** 또는 마우스 가운데 버튼으로 텍스트 위에서도 이미지를 이동할 수 있습니다. 배치만 바꾸므로 원본 및 출력 픽셀 크기는 유지되며 프로젝트·내부 저장·실행 취소에 포함됩니다.
- 숫자 입력, 슬라이더, 양옆의 −/＋ 버튼으로 크기·위치·회전·그림자를 조절합니다. 텍스트를 클릭해서 드래그로 이동하고, 선택 테두리 모서리로 크기, 위쪽 원으로 회전을 조절합니다.
- 상단 **초기화**는 현재 이미지를 유지하고 텍스트와 모든 편집 설정을 초기화합니다. 실행 취소로 복구할 수 있습니다. 각 조절 줄의 **C**는 값을 0으로 돌리며, 0이 불가능한 출력 크기·배율·글자 크기·감마는 기본값으로 복원합니다.
- 이미지 자체의 회전과 좌우·상하 반전을 지원하며, 텍스트의 회전·배치는 독립적으로 유지됩니다.
- 폰트, 색상, 두께, 정렬, 여러 줄과 여러 텍스트 레이어, 레이어 복제·삭제 및 실행 취소·다시 실행을 지원합니다.
- 톤: 밝기, 노출, 대비, 채도, 하이라이트, 어두운 영역, 색온도, 색조, 감마, 선명도, 흑백, 세피아, 비네팅.
- **업스케일 실행**은 원본 래스터를 더 많은 픽셀로 재생성하고 가장자리를 보정합니다. 예: 800×600 → 1600×1200. 배치 확대와 별개이며 AI 세부 복원은 포함하지 않습니다. 목표 크기에 맞춰 출력 캔버스도 커집니다.
- **프로젝트 저장/열기**: 원본 이미지와 텍스트·톤·배치를 포함한 `.jjimg` 파일을 저장하므로 원본 파일이 이동해도 다시 편집할 수 있습니다.
- **내부 저장/불러오기**: 곡별 편집 내용을 IndexedDB에 자동 저장합니다. 저장된 다른 곡의 편집 상태도 현재 편집기로 불러올 수 있습니다. 내부 저장 실패 시 표시되는 안내에 따라 프로젝트 파일로 저장하세요.
- 내보내기: PNG, JPEG, JPG, WebP, SVG, GIF. SVG는 배경 비트맵을 포함하고 텍스트는 벡터로 보존합니다. GIF는 내장 FFmpeg로 생성하는 정지 이미지입니다.
- 하단 **적용할 곡**에서 재생 목록의 대상 곡을 선택한 뒤 **저장하고 곡에 적용 / 적용 후 닫기**를 누릅니다. 처음에는 편집기를 연 곡이 선택됩니다. 다른 곡을 고르면 원래 곡의 편집 초안을 보존하고 선택한 곡에 새 이미지와 편집 프로젝트를 별도로 저장합니다. 재생 곡은 변경하지 않습니다.
- **저장하고 곡에 적용**할 때마다 새 PNG와 그 시점의 `.jjimg` 프로젝트를 앱 데이터 폴더에 보관하며 곡의 이미지 목록에 추가합니다. **곡 이미지 보관함 → 선택 이미지 편집**으로 이전 이미지의 레이어까지 다시 불러옵니다.
- **적용 후 닫기**는 곡 이미지와 편집 프로젝트·IndexedDB 저장을 완료한 뒤 닫습니다. 내부 저장 실패 시 편집기를 열어 두고 오류를 표시합니다.
- **붓 / 펜 / 형광펜 / 지우개 / 복제 도장**을 지원합니다. 색상, 출력 기준 두께, 농도(알파), 경도를 조절하며 펜 입력은 필압을 반영합니다. 형광펜은 납작한 모양과 낮은 기본 농도를 사용합니다.
- 그림 레이어는 추가·복제·삭제·순서 변경·표시·불투명도 조절을 지원합니다. 그림은 텍스트 아래에 합성됩니다. 지우개는 선택한 레이어만 지우며 **원본 이미지**를 선택하면 원본의 일부를 지워 여백 색상을 드러냅니다.
- 복제 도장 사용법: 도구를 **복제 도장**으로 바꾸고 **Ctrl+클릭**으로 복사할 위치를 지정한 뒤, 다른 부분을 드래그합니다. 지정 시점의 보이는 화면을 원본으로 사용하므로 문지르는 도중 같은 부분이 반복해서 섞이지 않습니다. 복사한 선과 원본도 프로젝트에 저장됩니다.
- 재생 화면의 **VISUAL STYLE → 이미지 슬라이드**에서 곡에 저장한 여러 이미지를 순서대로 표시합니다. 전환 간격(1~60초)과 전체 보기/채우기를 선택할 수 있으며, 일시정지·탐색은 오디오 재생 시간을 따라갑니다.


검증: `node --test tests/*.test.cjs`, `cargo check --manifest-path src-tauri/Cargo.toml --locked --offline`.
`tests/image-editor-browser.html`은 로컬 HTTP 서버로 열어 실제 Canvas 인코딩·IndexedDB·업스케일을 확인하는 합성 이미지 기반 테스트 화면입니다. **Run browser verification**을 누르면 결과를 표시합니다.


### Google AI Studio 이미지 생성·편집

설정창의 **API 키 발급 페이지 열기**로 [Google AI Studio 키 발급·관리](https://aistudio.google.com/apikey)를 기본 브라우저에서 열 수 있습니다. 주소도 설정창에 표시되어 복사할 수 있습니다.

AI 창의 **현재 편집 이미지**에는 텍스트와 그림을 포함한 실제 입력 이미지, 파일명과 편집 화면 크기를 표시합니다. AI 결과 보관함과 구분되며, 새 이미지 생성 모드에서는 이 이미지를 전송하지 않습니다.

IMG 편집 상단의 **AI 설정**에서 Google AI Studio API 키와 이미지 모델 ID를 입력합니다. 키를 이 PC에 보관하면 Windows 자격 증명 관리자에 저장하며, 보관을 해제하면 이번 앱 실행 동안만 사용합니다. 프로젝트·IndexedDB·AI 이미지 이력에는 API 키가 포함되지 않습니다. 저장된 키 삭제도 지원합니다.

**AI 생성·편집**은 별도 프롬프트 창을 엽니다. 새 이미지 생성 또는 현재 편집 화면의 AI 편집을 선택하고 프롬프트·비율·해상도를 설정합니다. 편집은 현재 텍스트와 그림을 합성한 화면을 긴 변 최대 2048px의 JPEG로 보내며, 프롬프트와 이미지가 Google에 전송됩니다. 실행 시 계정의 API 요금·할당량이 적용됩니다.

결과는 앱 데이터 폴더의 `ai-images/<곡 ID>/<작업 ID>/`에 이미지와 프롬프트·모델 이력으로 별도 저장합니다. AI 보관함에서 결과를 선택하고 **선택한 이미지를 편집기에 적용**을 누르면 현재 편집 화면을 교체합니다. 기존 편집 상태는 먼저 내부 저장하며 실행 취소로 텍스트·그림 레이어까지 복원할 수 있습니다. 이후 기존 **저장하고 곡에 적용** 또는 **적용 후 닫기**로 곡의 이미지 목록에 추가합니다.

기본 모델은 `gemini-nano-banana-2.1`이며 설정에서 계정에 사용 가능한 다른 이미지 모델 ID로 변경할 수 있습니다. `gemini-2.5-flash-image`는 해상도 선택 대신 모델의 기본 해상도를 사용합니다. 구현 기준: [Google 공식 이미지 생성·편집 문서](https://ai.google.dev/gemini-api/docs/generate-content/image-generation).

AI 요청은 네이티브 백엔드에서 고정된 Google HTTPS 엔드포인트로 보내며 자동 재시도하지 않습니다. 실제 Google 호출에는 사용자 API 키와 해당 모델 사용 권한이 필요합니다. 로컬 테스트는 유료 요청 없이 모의 API 응답으로 실행됩니다.


### 곡별 이미지 목록과 슬라이드 전환

재생 목록의 **🖼 숫자**는 연결된 이미지 개수입니다. 이미지가 없는 곡은 **🖼 +**로 표시합니다. 이 버튼이나 곡 우클릭 메뉴의 **이미지 추가 / 슬라이드 관리**를 눌러 재생 곡을 바꾸지 않고 관리할 수 있습니다. 시각화 상단 **이미지 관리**, 파일 정보의 이미지 관리 버튼, IMG 편집기의 곡 이미지 보관함에서도 열 수 있습니다.

- **이미지 여러 장 추가**에서 여러 파일을 한 번에 선택합니다. 앱의 해당 곡 전용 이미지 폴더에 사본을 보관하며 곡마다 최대 100장을 관리합니다.
- 이미지의 순서, 대표 이미지, 연결 해제를 설정한 뒤 **저장하고 닫기**를 누릅니다. 연결 해제는 원본 파일을 삭제하지 않습니다.
- 전환 효과: 페이드, 왼쪽 이동, 오른쪽 이동, 확대, 와이프, 바로 전환, 효과 섞기. 간격 1~60초, 전환 시간 0~3초, 전체 보기/채우기를 곡별로 저장합니다.
- 현재 곡에 이미지를 저장하면 VISUAL STYLE이 이미지 슬라이드로 전환됩니다. 전환 진행은 오디오 시간을 따라가며 일시정지하면 정지하고, 큰 구간을 탐색하거나 곡을 바꾸면 해당 이미지로 바로 이동합니다.
- 곡별 이미지 목록과 전환 설정은 재생 목록 및 `.jjp` 프로젝트에 저장합니다. 이전 버전의 프로젝트도 기본 전환 설정으로 열 수 있습니다.


### 이미지를 포함한 프로젝트 저장

상단의 프로젝트 저장은 각 곡의 대표 이미지와 슬라이드 이미지의 실제 데이터를 `.jjp` 파일 안에 포함합니다. 같은 이미지 경로는 한 번만 저장합니다. 이미지의 `.jjimg` 편집 프로젝트가 있으면 원본 이미지, 텍스트와 그림 레이어도 함께 포함합니다. API 키는 포함하지 않습니다.

프로젝트를 열면 이미지를 앱 데이터 폴더로 복원하고 경로를 다시 연결합니다. 원본 이미지를 이동하거나 삭제한 뒤에도 프로젝트에 포함된 이미지를 사용할 수 있으며, 이미지 순서와 곡별 전환 설정도 유지합니다. 기존 `.jjp` / JSON 파일도 열 수 있지만 실제 이미지까지 포함하려면 새 형식으로 다시 저장해야 합니다. 음원과 자막은 기존 파일 경로를 참조합니다.

이미지가 누락되면 저장 오류를 표시하고 기존 프로젝트를 불완전한 내용으로 덮어쓰지 않습니다. 프로젝트는 최대 512MB, 개별 이미지는 80MB까지 지원합니다.


### 막대 그래프 + 이미지 보기

VISUAL STYLE의 **막대 그래프 + 이미지**는 기본적으로 왼쪽에 실시간 막대 그래프, 오른쪽에 곡 이미지 슬라이드를 표시합니다. **위치 바꾸기** 버튼 또는 배치 선택으로 좌우를 바꿀 수 있으며 곡별 설정과 프로젝트에 저장됩니다.

이미지 슬라이드 및 혼합 보기에서 **슬라이드 간격**에 다음 이미지로 넘어갈 시간을 직접 입력합니다. 기본값은 **2초**이며 기존에 저장한 곡의 사용자 설정은 유지합니다. 전환 효과와 전환 시간은 별도로 조절합니다.


슬라이드의 **효과 없음**은 설정한 간격마다 애니메이션 없이 즉시 이미지를 바꿉니다. 기존 프로젝트의 ‘바로 전환’ 설정도 효과 없음으로 호환됩니다. 막대 그래프와 그래프+이미지 보기에는 상단 **0 dBFS** 점선을 표시하며, FFT 표시 범위를 −100~0 dBFS로 맞춥니다. 이는 주파수 스펙트럼의 기준선이며 음원의 전체 피크 미터와는 별개입니다.
